# CRT – HTF Stacks + Killzones + SMC + Elder Impulse

A single‑overlay TradingView indicator that bundles four tools:
- **HTF Candle Stacks** – stacked candles of up to 6 higher timeframes.
- **Killzones & Liquidity (EAT)** – ICT zones, BSL/SSL, 15‑min breakout, etc.
- **Smart‑Money‑Concepts (SMC)** – internal & swing structure, order blocks, FVG, etc.
- **Elder Impulse + EMA 200** – color‑coded candles, EMA plot, and impulse logic.

---
## 📦 Files
- `CRT COMBO/crtcombo.pine` – main source indicator.
- `XAUDXY Divergence Indicator/RSI_Divergence.pine` – reference RSI chart.
- `visual_companion.html` – placeholder for a visual companion (will host mock‑ups, diagrams).

---
## ⚙️ Installation
1. Copy `crtcombo.pine` into TradingView → *New script*.
2. Adjust any symbol defaults if needed.
3. Open the **Settings** panel and enable the master toggles you want.
